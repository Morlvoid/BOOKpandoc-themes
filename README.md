# BOOKpandoc-themes：假装出书主题库



项目介绍：本项目为假装出书（BOOKpandoc）的css主题库，你可以上传你创作的css主题或下载他人创作的css主题使用。



### 1. 如何提交主题

- **方式一：Pull Request**
  贡献者将主题文件夹（含 `.css`、`preview.png`、`info.json`）放在 `themes/` 下，提交 PR。
  你审核后合并，PR 合并即表示主题上线。

- **方式二：仅提交设计稿**
  如果不会写 CSS代码，可以将设计稿（图片）放到 `drafts/` 下，并在 PR 中说明。
  其他开发者看到后，可以选择将其实现为完整主题并提交 PR（可以注明原设计作者）。

- **方式三：若不会使用Github，请提交邮箱**

  邮箱地址：morlvoid@qq.com

## 5.如何下载和使用主题

BOOKpandoc 已经内置了简单的主题导入功能，用户可以通过以下任一方式安装：

#### 方式一：拖拽导入（最简便）

1. 将下载的 `.css` 文件（例如 `paper.css`）直接拖入 BOOKpandoc 主界面的“章节列表”区域。
2. 软件会提示“主题已导入”，并在“主题”下拉框中自动选中该主题。
3. 用户即可使用新主题导出书籍。

#### 方式二：通过“导入主题”按钮

1. 点击主界面右侧的“导入主题”按钮（如果有的话，或者通过“刷新”按钮旁边的菜单）。
2. 在弹出的文件选择对话框中，选择下载的 `.css` 文件。
3. 确认后，主题会被复制到软件的 `themes` 文件夹，并立即生效。

#### 方式三：手动复制到主题文件夹

1. 找到 BOOKpandoc 安装目录（如果是便携版，就是软件所在的文件夹）。
2. 进入其中的 `themes` 文件夹。
3. 将下载的 `.css` 文件复制进去。
4. 重启软件（或点击“刷新”按钮），主题就会出现在下拉列表中。

## 6.主题的切换与使用

- 在 BOOKpandoc 主界面，找到“主题”下拉框，里面会列出 `themes` 文件夹中所有可用的 `.css` 文件（包括用户自己导入的）。
- 选择任意主题，后续导出 EPUB、HTML、DOCX（部分格式支持）时，软件会自动应用该样式。
- 如果需要更换主题，只需重新选择即可。

## 7.常见问题与提示

##### Q1：下载的 CSS 文件没有生效怎么办？

- 确保文件后缀为 `.css`，且文件内容完整（可以用记事本打开检查是否有乱码）。
- 确认文件已被复制到正确的 `themes` 文件夹，或通过软件导入成功。
- 某些格式（如 DOCX）需要参考文档模板才能完全支持 CSS，HTML 和 EPUB 支持最好。

##### Q2：如何卸载不需要的主题？

- 直接打开软件的 `themes` 文件夹，删除对应的 `.css` 文件即可。主题下拉框会自动刷新。

##### Q3：我制作了一个主题，想分享给别人，应该怎么做？

- 将你的 `.css` 文件、一张预览图（建议 800×600）和一个简单的说明（名称、作者、描述）打包。
- 按照主题仓库的贡献指南，通过 Pull Request 提交到社区仓库，审核通过后所有人都能下载使用。

##### Q4：为什么我导入的主题在 EPUB 里没有样式？

- 请确认你的 EPUB 阅读器是否支持 CSS（推荐使用 Calibre 或 Thorium Reader）。
- 某些阅读器可能限制部分 CSS 属性，但基本样式（字体、颜色、边距）通常都有效。
